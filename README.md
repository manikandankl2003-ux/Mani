# Mani — HR Grace Website

This repository was initialized and contains a Vite + React + Tailwind starter with a single-page component for "HR Grace" (src/components/HRGraceWebsite.jsx).

How to run locally:

1. Install dependencies:
   npm install
2. Run the dev server:
   npm run dev
3. Open http://localhost:5173

Notes:
- Replace public/resume.pdf with a real resume file if you want the "Download Resume" links to work.
- The component is included as src/components/HRGraceWebsite.jsx and used in src/App.jsx.
